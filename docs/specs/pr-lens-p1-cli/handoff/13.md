## AnthropicLlmClient 조립 인터페이스
결정: `new AnthropicLlmClient(apiKey)` 또는 `new AnthropicLlmClient(apiKey, new AnthropicLlmClient.Options(baseUrl, timeout, masker, debugLog))`. 기본 `Options.defaults()`는 baseUrl null(SDK 기본), timeout 180초, 빈 `SecretMasker`, 디버그 로그 없음이다. 디버그 로그는 요청 요약과 오류 응답 헤더(`maskHeader` 적용)만 쓰고 키와 요청 본문은 쓰지 않는다
이유: `HttpGitHubClient.Options`와 같은 방식으로 맞췄다(결정 7.1)
영향받는 작업: 18.3 (조립 함수가 `Options`에 `SecretMasker`와, `PRLENS_DEBUG`가 켜졌을 때 stderr로 가는 `debugLog`를 넘긴다. 키는 `ANTHROPIC_API_KEY`에서 읽은 값을 이 생성자에만 넘긴다. 체인은 `RetryingLlmClient(AnthropicLlmClient, RetryExecutor)`)

## 13.4 스모크로 확인하지 못한 것
결정: 스모크는 2026-10-26에 실행했고 결과를 `docs/spikes/2026-10-26-claude-smoke.md`에 기록했다. 실제 API의 오류 응답(429, 5xx), `retry-after` 값의 모양, refusal 응답, 캐시 읽기(같은 앞부분으로 두 번째 요청), 400줄 단일 모드의 120초 측정은 확인하지 못했다
이유: 스모크 요청이 1건이고 정상 응답만 받았다
