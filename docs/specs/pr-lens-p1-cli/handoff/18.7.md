## prlens.cmd와 macOS 실행은 확인하지 않았다
결정: 18.7은 Linux(WSL)에서만 실행해 확인했다. `backend/scripts/prlens.cmd`(Windows cmd, PowerShell)와 macOS에서 `scripts/prlens`를 실행하는 것은 확인하지 않았고, `.cmd`의 `%~dp0`와 `%*`, `exit /b %ERRORLEVEL%`가 인자(공백, 따옴표)와 종료 코드를 그대로 넘기는지도 모른다
이유: 이 환경에서 Windows `cmd.exe`를 부를 수 없었고 macOS가 없다. CI는 세 OS에서 테스트를 돌리지만 `bootJar`와 래퍼는 돌리지 않는다
영향받는 작업: 20.4 (데모 리허설 때 Windows와 macOS에서 래퍼로 `prlens review`를 한 번 실행해 본다)
