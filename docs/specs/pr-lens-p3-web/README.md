# P3 웹 조회 스펙 색인

웹에서 PR별 리뷰 이력과 규칙 위반 통계를 봅니다(PRD FR-12~14, ROADMAP 4주차 M3).

- 상태 (2026-10-04): 요구사항만 있고 검토만 했습니다. **아직 고치지 않았습니다.** 요구사항을 고친 뒤 설계와 작업 목록을 새로 만들어야 합니다
- 문서: [requirements.md](requirements.md)
- 읽는 법은 [../README.md](../README.md)

## 수정 전에 확인할 것

**검토 결과**: [`docs/spec-review/06-p3-requirements.md`](../../spec-review/06-p3-requirements.md). 줄 번호는 검토 시점 기준이라 절 제목과 요구사항 번호로 찾습니다.

**확정된 결정 (2026-10-04)**
- 에러 형식 `ErrorResponse`, 경로 `/api/v1/`: [ADR 0008](../../adr/0008-keep-api-conventions.md)
- 404와 로딩 표시: 404가 필요한 화면에는 로딩 표시를 두지 않습니다. 요구사항이 둘을 동시에 요구하는 곳을 이 기준으로 고칩니다
- 통계의 중복 집계: PR별 최신 실행만 집계합니다

**P2에 먼저 반영해야 하는 것**: P3가 P2에 요구하는 추가·변경 16항목(페이지네이션, DTO 필드, `ReviewStore` 시그니처 등. 06번 "P3가 P2에 요구하는 추가·변경"). P2 구현 전에 반영하면 재작업이 줄어듭니다.

**아직 없는 것**: 요구사항이 전제하는 웹 테스트 도구(DOM 테스트, E2E, 속성 테스트, OpenAPI 타입 생성, 차트)가 설치돼 있지 않습니다(06번 "설치된 버전"). 무엇을 추가할지와 각 요구를 자동·수동 중 무엇으로 검증할지 정해야 합니다. 의존성 추가는 사람의 승인이 필요합니다.

**팀이 정할 것**: 결정 대기 D-1~D-12. 통계 기준인 D-3, D-4, D-12는 4주차 킥오프 전에 확정해야 합니다.
