# 문서 작성 규칙
이 규칙은 일어난 일을 기록하는 문장(실험·회고·검증 결과, 안내서의 현재 동작 설명)에 적용한다. 요구사항·설계의 규범 문장, 결정과 제안값(D-n, G-n)은 해당 없다.
- 수치·시각·커밋 SHA·테스트 개수는 원본(로그, `git log`, 테스트 리포트)과 대조해 적는다
- 확인하지 않은 것은 "확인하지 않음"으로 적고, 기대나 추정을 단정으로 쓰지 않는다
- 인용할 때는 원문을 바꿔 쓰지 않고, 요약하면 원문 위치를 가리킨다. 한 용어를 두 뜻으로 쓰지 않는다
